## Exalted & evolving skins now transform in-game

Selectable forms for Exalted and Legend (evolving) skins finally change the model in-game. Pick a form with the new variant button on the skin tile — the same way you pick a chroma — and the form is baked into the generated skin.

Fixed for: **Viego, Mordekaiser, Ahri, Kai'Sa, Jinx, Morgana and Sett**.

> Important: if you generated any of these skins before this update, delete the local file and generate it again so the fix takes effect.

Also improved:
- Forms now show descriptive names (Assassin, Mage, Tier 1, …) instead of a generic "Form N".
- Per-form preview images in the variant picker.
- Immortalized Legend skins (Ahri, Kai'Sa) no longer keep their recall throne stuck on the model.
